BigGeorge Property · Workshop Agenda

Részletes program

3 napos on-site workshop felépítése csapatonként.
Mindkét workshop ugyanezt a struktúrát követi, a csapat igényeire szabva.

Előzetes egyeztetés

Workshop előtt · ~2 órás meeting csapatonként

  • Tech stack áttekintés — milyen nyelvek, framework-ök, legacy részek vannak
  • Aktuális kihívások — hol fáj most legjobban a fejlesztésben
  • Fókusz kijelölése — melyik 2-3 területre koncentrálunk a workshopon
  • Előkészületek — tool hozzáférések, repo access, license-ek előkészítése

Eredmény: Közös megértés a kiindulási helyzetről, testre szabott workshop fókusz

1. nap

AI alapok, mindset, eszközök

A közös nyelv és szemlélet kialakítása — megérteni, hogyan gondolkodj AI-val

Délelőtt

AI és LLM alapok fejlesztőknek

  • Hogyan működnek a nagy nyelvi modellek (LLM-ek) — nem elméleti előadás, hanem gyakorlati megértés
  • Mi az, amiben az AI jó és miben nem — reális elvárások kialakítása
  • Prompt engineering alapok: hogyan kommunikálj hatékonyan az AI-val
  • Context window, token limit, temperature — ami a mindennapi használathoz kell

Délután

Eszközök és developer mindset

  • Tool landscape áttekintés: GitHub Copilot, GPT, Claude, Codex — melyik mire jó
  • AI-assisted coding workflow: nem a kód írása a lényeg, hanem az irányítás
  • Live demo: valós feladatok megoldása AI-val
  • Első saját próbálkozások — mindenki kipróbálja a saját környezetében

Nap vége

Retrospektív és fókusz a 2. napra

Mi működött, mi volt meglepő, mit akarunk holnap mélyebben kipróbálni.
2. nap

Testreszabás, ügynökök, folyamatok

A „generic" AI-ból a csapat saját eszközét csináljuk — customization és workflow építés

Délelőtt

AI finomhangolása saját use case-ekre

  • Custom instructions és system promptok — az AI-t a csapat kontextusára tanítjuk
  • Agent-szerepkörök definiálása: code reviewer, spec writer, tesztelő, refaktor asszisztens
  • agent.md, CLAUDE.md és hasonló konfigurációk felépítése a repo-ban
  • Saját projekt kontextusának betáplálása az AI-ba

Délután

Specification-driven development és dokumentáció

  • „Specification-driven development" — specifikáció mint a fejlesztés inputja, nem utólagos dokumentáció
  • AI-generált specifikációk, technikai dokumentáció, PR leírások
  • Eszközstack kialakítása: Copilot + GPT + Codex típusú eszközök együttes használata
  • CI/CD és repo-integráció — hogyan épül be az AI a meglévő workflow-ba

Nap vége

Workflow véglegesítés

A csapat saját AI workflow-jának dokumentálása és a 3. napi hands-on feladatok kiválasztása.
3. nap

Hands-on a saját feladatokon

A valódi munka — a csapat saját backlogjából dolgozunk, valós eredményekkel

Délelőtt

Közös munka a backlogon

  • A kollégák által hozott valós feladatok feldolgozása AI-val
  • Refaktor feladatok: legacy kód modernizálása AI asszisztenciával
  • Specifikáció generálás: meglévő feature-ökre visszamenőleg
  • Pair programming AI-val — valós tapasztalat szerzés

Délután

Feature fejlesztés és integráció

  • Új feature fejlesztés AI-asszisztenciával — a teljes ciklus végigvitele
  • Code review AI-val: hogyan használd review partnerként
  • Teszt generálás: unit és integration tesztek AI-val
  • PR készítés az új workflow szerint

Nap vége

Zárás és következő lépések

  • Workshop retrospektív — mérjük a 3 nap hatását
  • Egyéni action plan — ki mit visz tovább a mindennapi munkájába
  • Follow-up mentoring időpont egyeztetése

Follow-up mentoring

2-3 héttel a workshop után · 2 óra online, csapatonként

  • Tapasztalatok feldolgozása — mi működött, mi nem, hol akadtak el
  • Finomhangolás — workflow és tooling iteráció a valós tapasztalatok alapján
  • Mérés — lead time, PR ciklusok, dokumentáció idő összehasonlítás
  • Következő lépések — hogyan tovább, merre érdemes fejlődni

Mit kap a csapat

Workshop alatt

  • Felállított és testre szabott AI toolstack
  • 2-3 konkrét backlog item előrehaladása
  • Dokumentált workflow és prompt library
  • agent.md konfigurációk a repo-ban

Tartósan

  • AI-native fejlesztési kultúra
  • Önfenntartó prompt és workflow rendszer
  • Skálázható tudás — új tagok gyorsan felvehetik
  • Írásos összefoglaló és belső javaslatok
